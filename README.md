# Retail_Business_Dashboard
## Project Overview

***This project analyzes retail sales data using Microsoft Excel Features. The objective was to clean raw transactional data, create business metrics, and develop an interactive dashboard to monitor sales performance, profitability, customer behavior, and regional trends.***

## Dataset

  1.Rows: ~7,000
 
   2.Tool Used: Microsoft Excel Features inside WPS
   
   3.Domain: Retail Sales.

## Data Cleaning

The raw dataset contained several data quality issues that were cleaned before analysis:

Standardized date formats.(eg. 02/07/2002,09-05-2023)

Standardized and Trimmed extra spaces from text fields.(product,category,region columns)

Validated negative and invalid values.(quantity column)

# Handled missing values:

Missing Discount values replaced with 0.

Missing Unit Cost values replaced using the average Unit Cost.

## Calculated Columns

The following business metrics were created:

Sales Amount
Discount Amount
Revenue
Tax Amount
Production Cost
Profit
Profit Margin (%)
Delivery Days

## Dashboard Features

The interactive dashboard includes:

# KPI Cards
Total Revenue

## Key Insights
Electronics generated the highest overall revenue and profit.
Electronics products recorded the highest order volume.
West region consistently outperformed others in both revenue and profit.
Increasing the discount doesn't consistently increase or decrease the quantity purchased.
Profitability varied significantly across product categories.
Almost Equal amount of  customers preferred  both online and store to make purchases.
Highest Revenue is generated by Customers who paid by card.

## Recommendations
A large proportion of orders were returned, indicating potential issues with customer satisfaction, product quality, or order fulfillment.
Optimize discount strategies to improve profit margins.
Different membership types generated similar profit levels, suggesting that membership status alone did not significantly influence profitability.
Promote high-margin products through targeted campaigns.
Continue tracking customer ratings to maintain service quality.
